Slack Anchor Guy

Code 276
⚠️

Why Guys Are Needed

Check if mechanical loads on poles exceed their support capacity. When overloaded, additional strength must be provided using guys.

📋

Code 276 Usage

Use Code 276 (Slack Anchor Guy) to document when an anchor guy is found to be loose or has lost proper tension.

🔧

Maintenance Status

There is no on-site maintenance available for this condition. The issue must be reported and scheduled for proper repair.

🚨

Remember: A slack anchor guy cannot provide structural support — always document with Code 276!
